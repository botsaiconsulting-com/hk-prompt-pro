# 04 Starter pipeline (Theme 2, Part B)

1. `/hk pipeline .` If it asks which platform, answer with the one your team uses.
2. Read the plan aloud: what blocks, what warns, what needs a person's sign-off.
3. Approve, then let it run the build and test steps on your laptop.

Human check: the pipeline file holds no server name, password or connection string, and nothing in it deploys without a named person's sign-off. Connecting it to IIS is a separate follow-up session.
