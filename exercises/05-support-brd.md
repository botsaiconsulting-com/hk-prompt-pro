# 05 Support and documents (Theme 3)

Support team:
1. `/hk support add "<one recurring Gati issue and its fix, in your own words>"`, five times.
2. `/hk support answer "<text of support/tickets/T-101.md>"`, then T-102 to T-105.
3. One ticket has no matching entry. Hand it to a developer pair.

Developer pair taking the unmatched ticket:
4. `/hk debug "<text of T-105>, log in exercises/inputs/logs/api-2026-10-01.log"`. Read the hypotheses and the evidence before the fix.
5. `/hk support add` for the issue you found.

Other developers:
6. `/hk brd exercises/inputs/brd/rough-notes-top-customers.md`
7. `/hk brd spec docs/brd/<the file it wrote>`
8. `/hk brd form`

If time allows: `/hk check support`.

Human check: every reply cites a library entry or says "No matching entry"; the BRD lists what the notes did not say as open questions.
