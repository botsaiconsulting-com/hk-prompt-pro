# 06 Capstone (30 minutes)

Take `exercises/inputs/capstone/requirement.md` as far as you can, in this order:

1. `/hk brd exercises/inputs/capstone/requirement.md`
2. `/hk schema production-bags` if there is no pack yet, then `/hk sql "<the report, in plain words>"`
3. `/hk endpoint sql/<file>.sql`
4. `/hk test <the new endpoint or query>`
5. `/hk review <your branch>`
6. `/hk support add "<what users should know about the new report>"`

Human check: a person has read the BRD's open questions, the query's reconciliation checks and the review before anything merges.
