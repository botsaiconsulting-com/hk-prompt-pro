## Advanced track (architecture modules)

Concept modules the HK team added on top of the core day. Each card has a matching teaching note under `docs/modules/`. No code ships from these: you read the note, prompt Claude Code against the HK estate, compare with real GitHub projects, and write a design doc. The hard rules still hold - evidence or nothing, dummy data only, a person signs off anything that matters.
